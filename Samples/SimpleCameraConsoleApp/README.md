# Simple Camera Console App

This is a minimal C++ Win32 Console Application that demonstrates how to use WinRT APIs to enumerate cameras.

## Building the Project

1. Open the solution file in Visual Studio 2022
2. Build the solution (F7 or Ctrl+Shift+B)
3. Run the application (F5)

## Prerequisites

- Windows 10 or higher
- Visual Studio 2022 with C++ Desktop development workload
